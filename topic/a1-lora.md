
**LoRA**는 거대한 원본 모델 전체를 다시 학습시키는 대신, **원본 가중치는 그대로 얼려두고(Frozen) 옆에 아주 작은 보조 모듈(어댑터)만 붙여서 학습하는 효율적인 미세조정 기법**이다.

![](https://github.com/gnosia93/llm-train-ft/blob/main/images/lora.jpg)

### 1. 왜 LoRA를 쓸까?
기존의 전체 파인튜닝(Full Fine-Tuning)은 수십억 개의 파라미터를 전부 수정해야 하므로 막대한 GPU 메모리와 시간이 필요하다. LoRA는 전체 파라미터 중 **약 1% 미만의 핵심 변화량만 따로 학습**하기 때문에 적은 자원으로도 빠르고 가볍게 모델을 튜닝할 수 있다.

### 2. 그림으로 보는 작동 구조
* **원본 모델 가중치 ($W$):** 기존 모델이 가진 방대한 지식이다. 학습 중 값이 변하지 않도록 자물쇠로 잠가두어(Frozen) 기존 지식을 안전하게 보존한다.
* **LoRA 어댑터 ($A \times B$):** 원본 모델 옆에 새로 붙이는 얇은 학습용 행렬이다. 데이터를 아주 작은 차원(**Rank, $r$**)으로 압축했다가(행렬 $A$) 다시 원래 크기로 복원하면서(행렬 $B$) 새로운 패턴만 효율적으로 배운다.
  * **행렬 $A$ (축소/압축):** 입력 데이터를 작은 차원($r$)으로 압축하며 핵심 특징만 추출한다. (예: $1,000 \times 1,000$ 행렬을 $1,000 \times 8$로 축소)
  * **행렬 $B$ (확대/복원):** 압축된 $r$ 차원의 데이터를 다시 원래 크기로 복원한다. (예: $8 \times 1,000$으로 확대) 
* **강도 조절 ($\text{Scale} = \frac{\alpha}{r}$):** 학습된 LoRA 어댑터의 결과를 원본 모델 출력에 얼마나 강하게 더해줄지 결정하는 비율이다. 훈련 중 매 스텝의 업데이트 크기를 조절하는 핵심 계수로 작동한다.

> [!TIP]
> `LoRA의 실전 장점`
> 학습이 끝나면 수십 GB짜리 원본 모델 전체를 저장할 필요 없이, **수십 MB 크기의 작은 LoRA 어댑터 파일만 저장**하면 된다. 덕분에 하나의 원본 모델 위에 여러 작업용 어댑터(예: 쿠버네티스용, 번역용, 요약용)를 갈아끼우며 유연하게 활용할 수 있다.



### 3. 핵심 파라미터: `r`, `lora_alpha`, `scale` ###

LoRA 설정에서 가장 중요한 세 가지 값의 역할과 관계는 다음과 같다.

| 파라미터 | 쉬운 비유 | 실제 역할 | 특징 및 변화 여부 |
| :--- | :--- | :--- | :--- |
| **`r` (Rank)** | **요약 노트의 크기** | 어댑터가 담아낼 수 있는 **정보량(표현 용량)** 결정 | 설정 후 **고정(상수)**. 클수록 복잡한 지식을 담지만 메모리 사용량 증가 |
| **`lora_alpha`** | **볼륨 조절기의 기준값** | LoRA 학습 결과가 원본 모델에 미치는 **영향력(비중)** 조절 | 설정 후 **고정(상수)**. 실질적인 학습 보폭을 결정 |
| **`scale`** | **최종 출력 볼륨 (배수)** | 매 연산마다 LoRA 출력에 곱해지는 **최종 가중치 배수** | 설정 후 **고정(상수)**. 훈련 중 매 스텝 순전파·역전파에 실시간 적용 |

> [!INFO]
> `훈련 중 값의 변화 여부`
> 훈련이 시작되면 `r`, `lora_alpha`, `scale`은 모두 **변하지 않는 고정 상수**로 작동한다. 훈련 중 매 스텝마다 실제로 값이 업데이트되는 대상은 오직 **행렬 $A$와 행렬 $B$ 내부의 가중치**뿐이다. 학습 완료 후 저장되는 설정 파일(`adapter_config.json`)에도 이 `r`과 `lora_alpha` 값이 기록된다.

---

### 4. 실전 추천 세팅 조합 ###

특별한 이유가 없다면 **`lora_alpha`를 `r`의 1배(`scale = 1.0`) 또는 2배(`scale = 2.0`)로 맞추는 것**이 업계 표준이다.

1. **가벼운 말투·형식 교정 (SFT 기본 추천):** `r = 8`, `lora_alpha = 16` (`scale = 2.0`)
2. **전문 지식 학습 및 일반적 작업 (표준 밸런스):** `r = 16`, `lora_alpha = 32` (`scale = 2.0`)
3. **방대한 데이터 학습 (CPT 또는 고난도 추론):** `r = 32` 또는 `64`, `lora_alpha = 64` 또는 `128` (`scale = 2.0`)

> [!TIP]
> `LoRA 서빙 및 배포 장점`
> 학습이 끝나면 수십 GB짜리 원본 모델 전체를 다시 저장할 필요 없이, **수십 MB 크기의 작은 LoRA 어댑터 파일만 저장**하면 된다. 추론 시에는 원본 모델 위에 어댑터를 얹어 매 토큰마다 `scale`을 곱해 사용하거나, 필요시 원본 가중치에 어댑터를 영구적으로 합쳐(Merge: $W_{\text{new}} = W + \text{scale} \times A \cdot B$) 단일 모델로 배포할 수 있다.
