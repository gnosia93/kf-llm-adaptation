# 셸 스크립트 및 파이썬 정규표현식(Regex) 핵심 정리

쿠버네티스 공식 문서(`kubernetes/website`) 저장소 클론 및 마크다운 파싱 스크립트에서 사용된 주요 문법과 정규표현식을 정리한 문서입니다.

---

## 1. 셸 스크립트 디렉토리 확인 및 `git clone`

```bash
if [ ! -d raw/website ]; then
  git clone --depth 1 --filter=blob:none --sparse \
    https://github.com/kubernetes/website.git raw/website
fi
```

* **`-d raw/website`**: 해당 경로에 디렉토리(폴더)가 존재하는지 확인합니다.
* **`!`**: 논리 부정(NOT) 연산자입니다. 즉, `if [ ! -d raw/website ];`는 **"폴더가 존재하지 않는다면"**을 의미합니다.
* **`git clone`의 폴더 생성 동작**:
  * 대상 디렉토리가 없으면 자동으로 새 폴더를 생성하여 복제합니다.
  * 이미 비어 있는 폴더가 있으면 그 안에 복제합니다.
  * 이미 파일이 들어 있는 폴더가 있으면 덮어쓰기 방지를 위해 에러가 발생합니다. 따라서 중복 실행 시 에러를 피하기 위해 `if [ ! -d ... ]` 조건문을 사용합니다.
* **자주 쓰이는 기타 파일 테스트 옵션**:
  * `-f`: 일반 파일 존재 여부 확인
  * `-e`: 파일 또는 디렉토리 존재 여부 확인
  * `-s`: 파일이 존재하며 크기가 0보다 큰지(비어있지 않은지) 확인

## 2. Front Matter(YAML 메타데이터) 분리 정규식

### 정규식 패턴
```python
FRONT_MATTER_RE = re.compile(r"\A---\s*\n(.*?)\n---\s*\n", re.S)
```

* **`\A`**: 문자열의 맨 시작 위치에서만 매칭합니다. (문서 중간의 구분선 `---` 무시)
* **`---`**: Front Matter의 시작과 끝을 알리는 대시 3개입니다.
* **`\s*\n`**: `---` 뒤의 공백 및 줄바꿈을 포함합니다.
* **`(.*?)`**: 캡처 그룹 1로, 시작 `---`와 끝 `---` 사이의 순수 YAML 본문을 최소 일치(`*?`)로 추출합니다.
* **`re.S` (`re.DOTALL`)**: 점(`.`)이 줄바꿈(`\n`)까지 포함하여 매칭하도록 설정합니다.

### 파이썬 구현 예시 및 `or {}`의 역할

```python
import re
import yaml

FRONT_MATTER_RE = re.compile(r"\A---\s*\n(.*?)\n---\s*\n", re.S)

def parse_markdown(text: str):
    match = FRONT_MATTER_RE.match(text)
    if match:
        yaml_str = match.group(1)
        metadata = yaml.safe_load(yaml_str) or {}
        body = text[match.end():]
        return metadata, body
    return {}, text
```

* **`or {}`의 의미**: `---` 구분선만 있고 내부에 내용이 없거나 주석만 있는 경우 `yaml.safe_load()`는 `None`을 반환합니다. 이후 `metadata.get(...)` 호출 시 `AttributeError`가 발생하는 것을 막기 위해 기본값으로 빈 딕셔너리(`{}`)를 할당하는 안전장치입니다.

## 3. Front Matter 내 `title` 추출 정규식

### 정규식 패턴
```python
TITLE_RE = re.compile(r"^title:\s*(.+?)\s*$", re.M)
```

* **`^` 및 `re.M` (`re.MULTILINE`)**: 여러 줄의 문자열에서 각 줄의 시작이 `title:`인지 확인합니다.
* **`(.+?)`**: 실제 제목 값을 캡처 그룹 1로 추출하되, 뒤쪽 공백(`\s*`)까지 삼키지 않도록 게으른 매칭(`+?`)을 사용합니다.
* **후처리**: YAML에서 제목이 `"파드"`처럼 따옴표로 감싸져 있을 경우, 추출 후 `.strip('"'')` 메서드로 양끝 따옴표를 제거합니다.

## 4. 정규표현식 핵심 개념: 수량자와 플래그

### `(.+?)` 구조 분석
* **`( ... )`**: 나중에 `.group(1)` 등으로 꺼내 쓰기 위한 캡처 그룹입니다.
* **`.`**: 줄바꿈을 제외한 임의의 문자 1개를 의미합니다.
* **`+`**: 앞의 패턴이 **1개 이상** 연속으로 나옴을 뜻합니다.
* **`?` (수량자 뒤)**: 탐욕적(Greedy) 매칭을 억제하고 **가능한 한 가장 짧게(최소한으로) 매칭하는 게으른(Lazy) 수량자**로 만듭니다.

### 주요 수량자 비교
| 기호 | 의미 | 예시 (`a` 기준) | 설명 |
| :--- | :--- | :--- | :--- |
| **`+`** | 1개 이상 | `a+` | `"a"`, `"aa"` 매칭 (빈 문자열 실패) |
| **`*`** | 0개 이상 | `a*` | `""`, `"a"`, `"aa"` 모두 매칭 |
| **`?`** | 0개 또는 1개 | `a?` | `""` 또는 `"a"`만 매칭 |

### `re.S` (`Single line` 모드) 동작 원리
* `re.S`는 **Single line**의 약자입니다.
* 본문 중간의 개행 문자(`\n`) 자체를 삭제하거나 무시하는 것이 아니라, **점(`.`) 와일드카드가 `\n`까지 포함해서 인식할 수 있도록 허용 범위를 넓혀주는 옵션**입니다.

## 5. HTML 주석 제거 정규식

### 정규식 패턴
```python
COMMENT_RE = re.compile(r"<!--.*?-->", re.S)
```

* **`<!--` / `-->`**: HTML 주석의 시작과 끝 태그입니다.
* **`.*?`와 `re.S`**: 여러 줄에 걸친 주석도 줄바꿈을 넘어 매칭하되(`re.S`), 문서 내 다른 주석까지 한 번에 삼키지 않고 가장 가까운 `-->`에서 멈추도록(`*?`) 처리합니다.
* `COMMENT_RE.sub("", md_text)` 형태로 사용하여 주석을 빈 문자열로 제거합니다.

## 6. Hugo 숏코드(`glossary_tooltip`) 텍스트 추출 정규식

### 정규식 패턴
```python
TOOLTIP_TEXT_RE = re.compile(r'\{\{<\s*glossary_tooltip[^}]*?text="([^"]*)"[^}]*?>\}\}')
```

* **`\{\{<` ... `>\}\}`**: Hugo 숏코드의 시작과 끝 기호입니다.
* **`[^}]*?`**: `text="..."` 앞뒤에 다른 속성(`term_id` 등)이 올 수 있으므로 이를 건너뛰되, **현재 숏코드의 닫는 중괄호(`}`) 밖으로 넘어가지 않도록 제한**하는 핵심 안전장치입니다.
* **`text="([^"]*)"`**: `text="`와 닫는 `"` 사이의 실제 표시 단어만 캡처 그룹 1로 추출합니다.
* **활용**: `TOOLTIP_TEXT_RE.sub(r"\1", md_text)`를 통해 숏코드 전체를 그룹 1의 단어로 치환합니다.
